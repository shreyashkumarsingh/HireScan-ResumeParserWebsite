# HireScan - Resume Parser Website

A modern web application that intelligently parses resumes and scores them based on job role compatibility.

## Features

- 📄 **PDF Resume Upload** - Upload resume files in PDF format
- 🎯 **Job Role Matching** - Select from Web Developer, Software Engineer, Data Analyst, or ML Engineer
- 🔍 **Intelligent Parsing** - Extracts name, email, phone, and skills from resumes
- 📊 **Smart Scoring** - Scores resumes out of 10 based on job role relevance
- 🎨 **Modern UI** - Beautiful, responsive design with animations

## Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: EJS templating, Bootstrap 5
- **PDF Processing**: pdf-parse library
- **File Upload**: Multer

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation

1. Clone the repository
```bash
git clone https://github.com/shreyashkumarsingh/HireScan-ResumeParserWebsite.git
cd HireScan-ResumeParserWebsite
```

2. Install dependencies
```bash
npm install
```

3. Start the application
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

1. Upload a PDF resume file
2. Select the target job role
3. Click "Upload & Parse"
4. View the extracted information and compatibility score

## Deployment

This application is ready for deployment on platforms like Render, Heroku, or Vercel.
